## 5. 缺陷台账

开发与测试过程中发现并修复的缺陷（共 20 项，全部关闭）：

| # | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | 种子数据构建报 `tuple index out of range` | 物料元组字段数与取值下标不匹配 | 修正字段映射（价格/保质期/存储方式下标） |
| 2 | 种子库存随机货位越界（NoneType） | 货位编码生成未对照真实库区网格 | 增加 ZONE_GRID 网格与 pick_loc 取位函数 |
| 3 | `UNIQUE constraint failed: putaway_tasks.no` | 上架单号生成在同日重复 | 单号改为全局递增计数器 |
| 4 | 4 个货位体积超容 | 期初库存直接累加 used_cube | 按容量逐行压量（≤92%），超容清零 |
| 5 | 整仓库容利用率仅 29.6%，演示失真 | 压量过狠 | 调整 A/B 区单位容量与塞入策略，利用率 40.8% |
| 6 | 出库单满足率 0.38~0.86 | 订单行数量超出库存 | 订单行数量按「库存×50%−已下单」约束上限 |
| 7 | 驾驶舱「今日入库」为 0、趋势平坦 | ASN 上架未写流水 + 在途订单未分散 | 补写上架流水；在途单分散至近 3 天 |
| 8 | 临期批次样本为 0 | 随机效期全部 > 30 天 | 冷链物料按剩余 2~40 天定向生成 |
| 9 | 盘点准确率仅 75.86% | 差异行比例过高 | 差异行概率从 1/3 降至 1/8（准确率 96.55%） |
| 10 | 幂等重放读取错误列 | idem_keys 缺 response 列 | 表增加 response 列，重放返回首次响应 |
| 11 | volWeight 出现 `if False` 占位 | 模板残留 | 改为 体积(cm³)×1e6/6000 实算 |
| 12 | 可重复物料行重复扣库存 | POST /api/orders 未校验 | 增加同行重复物料合并提示（400） |
| 13 | 映射创建路由残留死代码 | `if False: pass` | 删除 |
| 14 | 前端「盘点作业 / 批次追溯」整页空白（PageError: Invalid or unexpected token） | trace.js 一处字符串引号不配对（'…' 以 " 结尾） | 修正引号；node --check 纳入自查 |
| 15 | 上架推荐命中已满货位（容量不足 400） | loc_score 需求体积下限 max(0.1 m³) 对小件失真，且单库区无位时回退同 SKU 旧位 | 下限改 1e-4；推荐失败跨库区兜底 |
| 16 | A 类物料全部挤入 B 拣货区导致无位可放 | 上架候选库区单一 | 候选链 B→A / A→B / C→A，跨区兜底 |
| 17 | 波次创建 500（pick_tasks.no 唯一冲突） | next_no 在未提交事务内循环取号，N 个任务同号 | 改为一次取基号 + 局部递增 |
| 18 | 盘点差异首次「已调整」必然 400（死锁） | 闸口要求"差异已生成调整流水"，但调整流水由本次动作生成 | 目标为已调整时闸口只校验审核放行 |
| 19 | 导出 CSV 文件名品牌残留「飞驰WMS」 | 复制脚手架未改 | 统一改为「飞传WMS」 |
| 20 | 多页面样式错位（表单/热力网格/追溯链） | style.css 缺少 WMS 扩展类 | 追加 120 行扩展样式（inp/kv-grid/loc-grid/trace-chain 等） |

## 6. 非功能验证

| 项 | 方法 | 结果 |
| --- | --- | --- |
| 限流 | 超 240 次/分钟触发 429 | 符合设计 |

| 并发写 | WAL + 全局写锁，冒烟脚本连续写 60+ 次 | 无 database is locked |
| 多通道令牌 | Bearer / X-Fc-Token / 查询串 / Cookie | 全部通过 |
| Key 鉴权 | 只读 Key 写操作 403、无效 Key 401 | 符合设计 |
| 断言健壮性 | 闸口失败统一 400 + missing 数组 | 前端可直接渲染闸口清单 |
