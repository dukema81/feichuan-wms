# 飞传WMS系统项目说明与操作手册

> 版本｜V1.0　适用｜飞传 WMS v1.0.0　读者｜仓库管理员、收货/拣货/发运/盘点岗位、系统管理员、对接开发　分类｜企业管理系统

## 1. 系统简介

飞传 WMS 是面向第三方仓储与电商仓的仓储执行系统（Warehouse Management System），覆盖
**收货 → 上架 → 分配 → 拣货 → 复核 → 发运 → 盘点 → 追溯** 全链路，并提供与 ERP / MES / TMS
对接的开放接口（API Key / Webhook / 增量同步）。

- 技术形态：Python 标准库单进程后端 + 原生 HTML/JS 前端，**零第三方依赖**；
- 演示数据：确定性生成（2 仓库 / 8 库区 / 100 货位 / 30 SKU / 22 张入库单 / 39 张出库单 /
  66 行库存），每次重建库完全一致。

## 2. 启动与登录

### 2.1 启动服务

```bash
cd feichuan-wms
python backend/server.py            # 默认端口 8022
# 自定义端口与数据库：
FEICHUAN_PORT=9000 FEICHUAN_DB=/data/wms.db python backend/server.py
```

## 3. 界面骨架

登录后进入主界面，自上而下四段：

1. **标题栏**：公司标识、系统名、版本、当前操作员、退出；
2. **菜单栏**：作业执行 / 库存管理 / 主数据 / 分析 / 系统 五个模块；
3. **工作区**：左侧功能树（15 个页面）+ 右侧内容区（KPI 卡 + 列表 + 详情）；
4. **状态栏**：当前仓库（WH-SZ01 苏州中心仓）、在库 SKU、待拣任务、库容、操作员。

## 4. 页面操作说明（15 页）

### 4.1 仓储驾驶舱（dashboard）

- 六张 KPI 卡：今日入库、今日出库、在库数量、库存货值、库容利用率、临期/异常；
- 近 14 天出入库作业量折线图（入库/出库/订单数三序列）；
- 库区负荷表（体积口径进度条）、出库状态分布、待办清单（待收货/待分配/待拣货/待审核/待补货）、
  最新异常、右侧库存健康快照与作业规则。

### 4.2 入库作业（inbound）

1. 点「新建 ASN」：选择供应商、填采购单号与预约日期（可指定月台、优先级），
   增加明细行（物料 + 数量，批次/效期可留空由系统按保质期推算）；
2. ASN 详情页按状态推进：
   - **草稿 → 已预约**：点「预约确认」（闸口：供应商启用、有明细、有预约日期）；
   - **已预约 → 已到货**：车辆到库后点「登记到货」；
   - **到货 → 收货**：点「登记收货」，逐行填实收数量与批次（可改批次/效期），
     超过计划 5% 会被拦截；
   - **收货完成**：全部收齐后点「收货完成」（有短收需填差异原因）；
   - **质检**：点「质检判定」，选择合格 / 让步接收 / 不合格，默认抽检 10%；
   - **上架**：点「生成上架任务」，系统按容量/集中度/ABC 推荐货位；逐条执行上架
     （可改目标货位），全部完成后 ASN 自动变为「已上架」；
   - **关闭**：点「关闭」结束入库流程。
3. 详情页中的「状态闸口」面板实时显示每个目标状态的通过/缺失项。

### 4.3 出库作业（outbound）

1. 点「新建出库单」：选客户、优先级、截单时间，填明细（物料 + 数量）；
2. 出库单详情按链路推进：
   - **提交**：草稿确认后进入已提交；
   - **分配**：点「库存分配」，系统按 FEFO（默认，可改 FIFO/LIFO 规则）锁定批次，
     满足率 100% 自动变已分配；缺量会保持已提交并生成「库存不足」异常；
   - **拣货**：可整单拣货，或先到「波次拣货」页组波；「拣货单」可打印
     （含蛇形路径、距离与工时估算）；
   - **打包**：填箱数（留空用系统按体积/重量估算），生成包裹号与体积重；
   - **发运**：确认承运商，系统生成运单号与运费估算；
   - **签收**：TMS 回传后点「签收」完结。

### 4.4 波次拣货（wave）

- 「可组波订单」列出已分配且未入波的订单；
- 选择组波规则（按承运商 / 截单时段 / 客户 / 库区），点「生成波次」（可自动挑选）；
- 波次行点「下发拣货」→「整波拣货」→ 自动完成；详情显示拣货顺序、距离与工时。

### 4.5 盘点作业（stocktake）

1. 点「发起盘点」：选库区（默认全仓）与方式——**明盘**带出账面数，**盲盘**只显示货位与物料；
2. 盘点单详情内联录入每个货位的实盘数（系统自动算差异）；
3. 录完后「提交审核」→ 审核人（仓储经理/盘点审核）「审核调整」：
   系统按差异自动生成盘盈/盘亏流水并修正库存与货位体积 → 「关闭」。

### 4.6 库存台账（stock）

- 批次明细 / 按物料汇总两个页签；可按「仅可用」「临期」过滤，支持搜索与 CSV 导出；
- 点击行直接跳转该批次的追溯页。

### 4.7 库位管理（locations）

- 库区负荷卡 + 100 个货位的热力网格（颜色越深占用越高）；
- 点击库区卡片过滤；点击货位格子查看该位库存。

### 4.8 补货移库（replenish）

- 系统按拣货面水位（下限 12 / 上限 60）与在途需求给出补货建议；
- 「按建议生成任务」→ 拣货位人员执行「补货完成」；
- 「新建移库」做库内货位调整（校验源货位可用量与目标货位存在性）。

### 4.9 批次追溯（trace）

- 输入批次号：显示「入库来源（供应商/ASN）→ 当前在库（货位分布）→ 出库去向（客户/运单）」
  三段链路 + 全部流水；
- 输入出库单号：反查该单消耗的全部批次。

### 4.10 物料主数据（items）

30 个演示 SKU；支持按品类 / ABC 过滤与搜索；新建/编辑含尺寸重量（用于体积与装载计算）、
保质期（用于效期推算）、安全库存（用于水位预警）；详情页展示库存分布、批次与最近流水。

### 4.11 往来单位（partners）

供应商 / 客户 / 承运商三个页签，均可新建。客户冻结后不能开出库单；承运商停用后不能发运。

### 4.12 报表分析（reports）

7 / 14 / 30 / 90 天切换：出入库趋势、承运商绩效（票数/准班率/运费）、客户金额 TOP、
物料消耗 TOP10、人员绩效、ABC 结构、临期分布、库区负荷；两枚按钮分别导出出库单与库存 CSV。

### 4.13 集成中心（integration，仅管理员）

- **总览**：对接方式速查（Key 前缀、签名算法、重试策略、增量同步入口）与 25 类事件清单；
- **API Key**：生成 Key（明文仅显示一次）、吊销；
- **Webhook**：登记回调地址与订阅事件，查看 secret（仅显示一次），发送测试事件；
- **投递记录**：每次投递的状态 / 次数 / HTTP 码 / 错误，可手工重投；
- **外部映射**：绑定 ERP 单号 ⇄ WMS 单号，支持双向反查；
- **增量同步**：输入游标拉取变更（每页最多 500 条）。

### 4.14 基础设置（settings）

仓库与库区、12 条业务规则（超收容差、抽检率、FEFO、补货上下限、临期天数、波次上限等，
在线修改即时生效）、8 类账号与权限矩阵、系统信息。

### 4.15 操作日志（logs）

全量审计：操作人、动作、对象单号、时间、IP，支持关键字过滤。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 登录提示「网络异常」 | 确认服务已启动、端口正确；`/api/health` 自检 |
| 提示「闸口未通过」 | 详情页「状态闸口」面板查看缺失项，按提示补数（如先质检再上架） |
| 分配后仍是「已提交」 | 库存不足：查看异常页「库存不足」单，补货或调低数量后重新分配 |
| 上架提示容量不足 | 系统已自动跨库区推荐；仍不足时先移库腾位或改用更大货位 |
| 收货提示超收 | 超过计划 5% 容差；核对送货单，或分批收货 |
| 找不到某批次 | 库存台账搜索批次号；数量为 0 的批次只保留最后一行流水 |
| Webhook 投递失败 | 检查回调地址可达性与签名（timestamp + "." + body）；投递记录可重投 |
| 修改规则未生效 | 基础设置保存后即时生效；注意分配策略改动只影响后续分配 |

## 8. 运维与备份

- **备份**：直接复制 `backend/data/feichuan.db`（WAL 模式建议先 `POST /api/auth/logout`
  或低峰期操作）；恢复即替换文件并重启服务；
- **日志**：`op_logs` 表记录全部写操作；界面「操作日志」页可查；
- **升级**：替换源码后重启；数据库结构由 `init_db()` 自动迁移（新增表与列）；
- **重置演示数据**：停服后删除 `backend/data/feichuan.db*`，重启即重新生成。
